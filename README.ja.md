# jibun-de-mamoru（自分で守る）

[English](README.md) | 日本語

漏えい通知が届いた個人向けの、1枚・端末内完結のページです。届く前の準備にも使えます。

**公開ページ:** https://sunnydachs.github.io/jibun-de-mamoru/

## 何ができるか

2026年10月6日にデジタル相が「自分の情報は自分で守る」と呼びかけました。
「企業が漏らすのに個人は何ができるのか」への答えを2つの形で置いています。

1. **「自分で守る」実行チェック** — 政府の3つ（パスワード使い回しをやめる／
   多要素認証／不審なリンクを踏まない）にAIサービスの学習設定を加え、
   **1つだけやっても成立する形**に落とした5項目。根拠は公的機関のリンク付き。
2. **漏えい通知の台帳** — 既存の無料ツールに無い部分です。通知元・通知日・
   漏れた情報の種類を記録すると、**期限つきの次の一手（今日中／1週間／30日）**
   に変換し、複数件の通知を重ねて管理できます。全体をテキストで書き出せます。

## なぜ「状態を持つ」ことが大事か

既存の無料ガイドはステートレスです — 汎用の助言を返して、あなたのことを
忘れます。どのサービスのパスワードを変えたか、カードの補償期限や信用情報の
本人申告がまだ開いているか、2件目・3件目の通知が何を足したか —
そうした**自分の記録**を保持するものは無料では存在しません。このページは
それだけを持ち、それ以外は何も持ちません。

## プライバシーと限界（ページにも明記）

- すべて**端末内（ブラウザのlocalStorage）**で完結。どこにも送信しません。
  端末変更やブラウザのデータ削除で消えます。
- **何も保証しません。** 企業側の漏えいは個人では防げません。手順は公的機関
  （警察庁・個人情報保護委員会・国民生活センター等）と公式ページに基づく
  一般的な注意喚起で、個別状況の法的・技術的判断ではありません。
- 手順は古くなります。リンク先の公式ページを確認してください。
- 実際の被害＝警察のサイバー相談窓口、消費者トラブル＝188。
